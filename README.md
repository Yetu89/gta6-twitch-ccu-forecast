A comparable-shape quantile forecaster: it estimates the launch-day diurnal shape of Twitch viewership from the past big game launches in the case file and forecasts hours 2–24 of GTA VI's release day as five quantiles per hour, scored by pinball loss on the log scale.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
